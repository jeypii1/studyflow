# StudyFlow

StudyFlow is a responsive student productivity dashboard for organizing schoolwork, tracking progress, and running focused study sessions from one clean workspace.

![StudyFlow preview](public/og.png)

## Features

- Add, edit, complete, delete, search, and filter tasks
- Organize tasks by subject, priority, date, and time
- View upcoming work in a weekly calendar
- Run 25-minute Pomodoro focus sessions
- Track task completion and study-session progress
- Switch between light and dark themes
- Save tasks and preferences locally in the browser
- Use the dashboard comfortably on desktop and mobile

## Built with

- Next.js and React
- TypeScript
- Tailwind CSS
- Browser local storage

## Run locally

Install [Node.js](https://nodejs.org/) and then run:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Project structure

```text

  globals.css    Global styles, themes, and animations
  layout.tsx     Page metadata and root layout

```
